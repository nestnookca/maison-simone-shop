# Maison Simone

Site vitrine (démo) pour une boutique spa/soins du visage — HTML/CSS/JS statique, sans backend.

- Catalogue de produits (soins visage + appareils professionnels)
- Panier + tunnel de commande simulé (aucun paiement réel n'est traité)
- Page "La Maison" (histoire/équipe), page boutiques (concept kiosque), contact
- Français canadien, entièrement responsive

## Développement local

```
python -m http.server 8123
```

Puis ouvrir `http://localhost:8123`.

## Déploiement

Site 100% statique — déployable tel quel sur GitHub Pages, Netlify, Vercel ou tout hébergement statique, avec le domaine `maisonsimon.shop`.
